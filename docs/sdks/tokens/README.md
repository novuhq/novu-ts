# Subscribers.Tokens

## Overview

### Available Operations

* [create](#create) - Create a subscriber login token

## create

Create a short-lived, Novu-signed login token for the subscriber identified by **subscriberId**.
    Call it from your backend with your secret key, then pass the token to the browser, which exchanges it for an Inbox session.
    Creating a token does not read or change the subscriber, so the subscriber does not need to exist yet.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="SubscribersController_createSubscriberToken" method="post" path="/v2/subscribers/{subscriberId}/tokens" -->
```typescript
import { Novu } from "@novu/api";

const novu = new Novu({
  secretKey: "YOUR_SECRET_KEY_HERE",
});

async function run() {
  const result = await novu.subscribers.tokens.create({
    context: {
      "key": "org-acme",
    },
    subscriber: {
      firstName: "John",
      lastName: "Doe",
      email: "john.doe@example.com",
      phone: "+1234567890",
      avatar: "https://example.com/avatar.jpg",
      locale: "en-US",
      timezone: "America/New_York",
    },
    scope: [
      "channels:shared",
    ],
    expiresIn: 600,
  }, "<id>");

  console.log(result);
}

run();
```
